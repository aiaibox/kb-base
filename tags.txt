# Controlled tag vocabulary. One copy, in kb-base, read by lint in every repo —
# repos differ by SENSITIVITY, not by subject,
# so a domain valid in one is valid in all. Adding a tag is a deliberate edit
# here, never something done in passing.
#
# Principle: tag only what full-text search cannot find. A note mentioning
# Chase is findable by searching "Chase"; a note that IS a decision is not.
# Specific entities — people, companies, tickers, places — belong in the title
# and body, never here.
